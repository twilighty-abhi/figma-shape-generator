## Description
Make playful decorative shapes and stickers in seconds, no drawing required.

Shape Maker generates 42 kinds of shapes as clean, native Figma vectors. Recolor, resize, boolean and edit them like anything you drew yourself, or reopen the plugin and keep tweaking them later.

**Shapes**
• Geometric: scallops, scallop & petal rings, flowers, daisies, clovers, starbursts, badges, stars, sparkles, asterisks, wavy & scalloped bars, ribbons, squiggles, zigzags, arches, half circles, sunbursts
• Freeform: blobs, puffs, splats, wobbly & wild flowers, worms, curls, hand-drawn stars
• Stickers: hearts, speech & cloud bubbles, arrows, loop arrows, leaves, smileys, flower smileys, text badges ("NEW") and sale bursts

**How it works**
• Pick a shape and fine-tune it with sliders (lobes, depth, petal shape, irregularity, holes, center dots and more)
• Add a hand-drawn feel to any shape with Wobble and Rough edge
• Browse variations and click one to use it, or hit Space to shuffle
• Insert one shape, or a whole sheet of up to 100 random shapes in your palette
• Edit later: select an inserted shape and open the plugin (or click **Edit shape** in the right panel). Slider and color changes update it in place
• Scatter: select a frame and fill it with randomly placed shapes. Set the count, size range, overlap, bleed past the edges and random rotation, and choose whether they sit behind your content
• Text badges and sale bursts come with a real text layer, so you can just retype the label
• Colors: use the built-in palette, add your own, or pick from the file's paint styles and color variables. Shapes stay linked to those styles and variables
• Select a frame first to insert shapes straight into it

**Shortcuts**
Space: shuffle · Enter: insert · V: new variations · ← →: previous / next shape

Shape Maker works offline. It makes no network requests and collects no data.

## Data security disclosure (asked during publishing)
- Network access: **none**
- Collects user data: **no**
- Stores data: **the user's color palette, locally via `figma.clientStorage`; and each generated shape's settings, saved as plugin data on that layer inside the user's own file (so it can be re-edited)**
- Reads document data: **only the file's local paint styles and color variables (read-only), to offer them as colors**
- See `PRIVACY.md`
